# AI 업무자동화 키트

Claude Code 와 대화하면서 **내 업무 중 무엇을 자동화할 수 있는지** 찾아보고, 가능하면 **첫 자동화까지 직접 만들어보는** 키트입니다. 개발자가 아닌 분들을 위해 만들었습니다.

- Claude 가 1:1 인터뷰처럼 하나씩 물어보면서 반복 업무를 찾아냅니다.
- 조건이 맞으면 그 자리에서 자동화를 만들고, 내 샘플 파일로 시험까지 합니다.
- 끝나면 회사 정보를 지운 리포트를 만들어 진행자에게 보낼 수 있습니다.

## 받기

👉 **[키트 다운로드 (zip)](https://github.com/hi8735/ai-automation-kit/releases/latest/download/ai-automation-kit.zip)**

이 페이지 위쪽의 초록색 `Code` 버튼으로 받지 마세요 — 키트 외의 파일이 섞여 들어갑니다. 위 링크는 항상 최신 버전을 받습니다.

## 시작하기

압축을 풀고 폴더 안의 `README.md` 를 따라 하시면 됩니다. 요약하면:

1. 압축 풀기 — `CLAUDE.md` 파일과 `inputs` 폴더가 바로 보이는 폴더가 키트 폴더입니다.
2. 그 폴더에서 Claude Code 실행 (터미널의 `claude`, 또는 Claude 데스크톱 앱의 Code)
3. "이 폴더를 신뢰하시겠습니까?" → **예**
4. `/start` 입력

필요한 것: Claude 유료 플랜 + Claude Code.

## 명령

| 명령 | 하는 일 |
|---|---|
| `/start` | 인터뷰 시작 / 이어서 하기 |
| `/build` | 고른 업무로 자동화 만들기 |
| `/run 이름` | 만든 자동화 다시 실행 |
| `/report` | 제출용 리포트 만들기 (회사 정보 제거, 본인 확인 후) |

## 이 레포 구조

```
kit/    ← 참가자가 받는 키트 원본 (Releases 의 zip 이 이 폴더를 압축한 것)
docs/   ← 사용설명서 페이지 (GitHub Pages)
```
