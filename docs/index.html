03

시작하기

내 컴퓨터에 맞는 탭을 골라 순서대로 따라 하세요.

  1. 키트 받기

    키트 다운로드를 눌러 ai-automation-kit.zip 을 받아요. 보통 다운로드 폴더에 저장돼요.

  2. 압축 풀기

    zip 파일을 오른쪽 클릭 → 모두 압축 풀기. 풀 위치는 찾기 쉬운 곳으로 바꿔주세요. 추천: C:\ai-work

    !폴더가 두 겹으로 풀릴 수 있어요. 그럴 땐 안쪽 폴더가 진짜예요. CLAUDE.md 파일과 inputs 폴더가 바로 보이는 폴더를 찾으세요.
    C:\ai-work\ai-automation-kit\ 여기 아님
      └ ai-automation-kit\ 여기서 실행
         ├ CLAUDE.md
         ├ inputs\ · results\ · report\ …
    i바탕화면이나 OneDrive 폴더는 피하는 게 좋아요. 동기화 때문에 가끔 문제가 생겨요.

  3. 그 폴더에서 Claude Code 열기

    터미널로 쓰는 경우: 키트 폴더를 연 상태에서 위쪽 주소창을 클릭하고 cmd 를 입력한 뒤 Enter. 검은 창이 뜨면 아래를 입력하고 Enter.

    claude

    데스크톱 앱으로 쓰는 경우: Claude 앱 → Code → 작업 폴더로 키트 폴더를 선택.

  4. "이 폴더를 신뢰하시겠습니까?" → 예

    처음 한 번 물어봐요. 예(Yes) 를 골라야 키트가 제대로 동작해요.

  5. /start 입력

04

Claude Code 안에서는 무슨 일이?

대화에 집중하다 보면 지금 어디쯤인지 헷갈릴 수 있어요. 이 지도를 옆에 띄워두면 각 단계에서 Claude 가 무엇을 하고, 내가 무엇을 하면 되고, 폴더에 무엇이 생기는지 한눈에 보여요.

인사와 닉네임

/start 를 치면 바로 시작돼요

Claude 가 하는 일

  • 키트를 짧게 소개하고 진행 시간을 알려줘요
  • 내 컴퓨터 환경(Windows/Mac, 엑셀 처리 도구 유무)을 조용히 확인해요
  • 지난번 기록이 있으면 이어서 할지 물어요

내가 할 일

  • 당근 모임 닉네임을 알려주기 — 진행자가 이 이름으로 1:1 연락을 드려요

Claude 가 이렇게 말해요

"넣어주신 파일과 여기 적어주신 내용은 Claude 로 전송돼요. 회사에 다니시면 회사 규정을 한번 확인해 주시고, 가능하면 민감한 부분을 지운 샘플을 써주세요."

갈래 고르기

두 갈래 중 하나를 번호로 골라요. 애매하면 2번이 좋아요.

1번 · 하고 싶은 일이 있어요

  • 그 일을 한두 문장으로 설명
  • "자동화되면 나는 무엇만 하면 되나" — 완성된 모습을 같이 그려요
  • 더 좋은 후보가 있는지 2~3분 짧게 훑어봐요

2번 · 아직 잘 모르겠어요

  • "무엇을 자동화하고 싶으세요?" 라고 묻지 않아요
  • 대신 최근 하루를 같이 되짚으며 Claude 가 반복 업무를 찾아내요
  • 익숙해서 안 보이던 일이 여기서 나와요

업무 찾기

이 키트에서 가장 중요한 단계예요. 서두르지 않아요.

Claude 가 하는 일

  • 하루 흐름을 듣다가 "옮겨 적기", "여러 파일 합치기", "매번 같은 답장" 같은 자동화 신호를 잡아 되물어요
  • 후보마다 빈도·시간을 물어 한 달에 몇 시간 드는지 계산해요
  • 몇 번 답할 때마다 "제가 이해한 게 맞나요?" 로 정리해요

내가 할 일

  • 사소한 일도 편하게 말하기 — 사소한 일에서 줄일 게 많이 나와요
  • "귀찮다", "실수한다" 같은 느낌도 솔직하게

폴더에 생기는 것

results/interview.md — 대화 내용이 단계마다 저장돼요. 끊겨도 여기서 이어져요. 내 PC 에만 두는 파일이에요.

후보 고르기

후보마다 자동화 가능성을 A~D 로 알려줘요

등급의 뜻

  • A 지금 이 폴더에서 바로 가능 — 파일·엑셀·문서·글 작업
  • B 연결 설정이 필요 — 메일함, 구글 드라이브, 노션 등
  • C 사내 시스템·웹사이트를 직접 눌러야 함 — 가능하지만 잘 깨져요
  • D 맞지 않음 — 사람의 판단·책임이 핵심이거나 보안상 어려움

Claude 가 하는 일

효과가 가장 큰 일과 오늘 바로 성공할 일을 따로 보여줘요. 처음엔 성공할 일로 시작하는 걸 추천해요.

내가 할 일

어느 걸로 할지 고르기. 결정은 내가 해요.

깊이 파기와 진단

말로 하는 설명과 실제 작업은 거의 항상 달라요. 그래서 실제를 따라가요.

Claude 가 하는 일

  • "지난번에 그 일 할 때 맨 처음 뭘 열었어요?" 부터 한 단계씩
  • 규칙대로 되는 부분과 내가 판단하는 부분을 나눠요
  • 등급, 추천 방식, 예상 절감 시간, 한계를 정리해요

내가 할 일

  • 가능하면 샘플 파일이나 화면 캡처를 inputs 폴더에 넣고 파일 이름 알려주기
  • 한글(.hwp)·워드는 PDF 로 저장해서

안 되는 건 안 된다고 말해요

"다음 날 멈출 걸 '된다'고 말씀드릴 수는 없어서 미리 말씀드려요. 대신 손이 가는 부분을 확 줄일 방법은 있을 수 있어요."

만들기 — A 등급이고 샘플이 있을 때

"지금 바로 만들어볼까요?" 라고 물어요. 싫으면 건너뛰어도 돼요.

Claude 가 하는 일

  • 인터뷰에서 들은 내 업무 방식 그대로 자동화 문서를 써요
  • 엑셀이 필요하면 작은 프로그램도 만들어요 (허락 창이 떠요)
  • 내 샘플로 실제로 돌려보고 결과를 보여줘요

내가 할 일

  • 결과가 평소 내가 만들던 것과 같은지 확인
  • 다른 점을 말하면 고쳐서 다시 돌려요

폴더에 생기는 것

automations/이름/ 자동화 문서와 사용법 · outputs/ 결과물 (실행할 때마다 새 파일)
다음부터는 파일을 inputs 에 넣고 /run 이름 만 치면 돼요.

리포트

/report — 중간까지만 했어도 만들 수 있어요

Claude 가 하는 일

  • 당근 닉네임을 한 번 더 확인
  • 회사·사람·고객 이름, 연락처, 금액을 지운 초안을 써요
  • 남은 게 없는지 스스로 점검한 뒤 전문을 보여줘요

내가 할 일

  • 읽어보고 빼고 싶은 게 있으면 말하기
  • 괜찮으면 "보내도 돼요"

막혔을 때

여기 없는 문제는 어디서 어떻게 막혔는지(화면 캡처면 더 좋아요) 모임 채팅방에 남겨주세요.

Claude Code 가 아직 없어요

설치 가이드를 따라 하시면 돼요. Claude 유료 플랜(Pro 이상)이 필요해요.

/start 를 쳤는데 반응이 이상해요

키트 폴더가 아닌 곳에서 실행했을 가능성이 커요. CLAUDE.md 파일과 inputs 폴더가 바로 보이는 폴더에서 다시 열어주세요. 압축을 풀었더니 폴더가 두 겹이 된 경우가 가장 흔해요.

중간에 창을 닫았어요 / 멈췄어요

같은 폴더에서 Claude Code 를 다시 열고 /start. 대화 내용이 단계마다 저장되어 있어서 멈춘 곳부터 이어져요.

"사용량 한도" 메시지가 나와요

플랜의 사용량을 다 쓴 거예요. 표시된 시간이 지난 뒤 다시 열고 /start 하면 이어집니다.

허락을 묻는 창이 자꾸 떠요

Claude 가 파일을 만들거나 프로그램을 실행할 때 확인을 받는 거예요. Claude 가 바로 앞에서 무엇을 하려는지 설명하니, 괜찮으면 예를 눌러주세요. 처음에 "이 폴더를 신뢰하시겠습니까?" 에 예를 눌러야 확인 창이 줄어들어요.

엑셀·한글 파일을 못 읽는대요

한글(.hwp)·워드는 "다른 이름으로 저장 → PDF" 로 저장해서 넣어주세요. 엑셀은 Claude 가 엑셀 처리 도구(Python) 설치를 도와드려요. 회사 PC 라 설치가 막히면 "다른 이름으로 저장 → CSV UTF-8" 로 저장해서 넣으면 돼요. 아이폰 사진(.heic)은 화면에 띄워 스크린샷을 찍어 넣어주세요.

회사 파일을 넣어도 괜찮을까요?

넣은 파일과 대화 내용은 Claude 로 전송돼요. 회사 규정을 먼저 확인해 주시고, 가능하면 이름·연락처·금액을 가짜 값으로 바꾼 사본을 써주세요. 그래도 충분히 진행돼요. 파일 없이 말로만 해도 괜찮아요.

키트 새 버전이 나왔대요

새 zip 을 원래 키트 폴더와 같은 위치에 풀고, "파일을 바꾸시겠습니까?" 가 나오면 예. 인터뷰 기록과 만든 자동화는 그대로 남아요. 다운로드 링크는 항상 최신 버전을 받아요.

만든 자동화는 다음에 어떻게 써요?

새 파일을 inputs 에 넣고, 키트 폴더에서 Claude Code 를 연 다음 /run 이름. 이름이 기억 안 나면 /run 만 쳐도 목록을 보여줘요.
