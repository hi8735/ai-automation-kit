코치 앱 설치하기

붙여넣기 한 번이면 설치가 끝나요. 그다음부터는 바탕화면 아이콘을 더블클릭하면 브라우저에 대화 화면이 열려요. Claude Code 를 따로 설치할 필요도 없어요.

걸리는 시간 3~5분 필요한 것 Claude 유료 플랜 관리자 권한 필요 없음
설치하면 이렇게 써요

1. 바탕화면 AI 업무자동화 코치 더블클릭

2. 브라우저가 열리면 Claude 계정으로 로그인 (처음 한 번)

3. 인터뷰 시작하기 버튼 → 대화로 진행

파일은 화면 왼쪽에 끌어다 놓으면 돼요

01

설치하기

내 컴퓨터에 맞는 탭을 골라 순서대로 따라 하세요.

  1. PowerShell 열기

    키보드의 Windows 키를 누르고 PowerShell 입력 → Windows PowerShell 클릭. 파란(또는 검은) 창이 열려요.

  2. 아래 한 줄 붙여넣고 Enter

    복사를 누르고, 창에서 마우스 오른쪽 클릭(또는 Ctrl+V) → Enter.

    irm https://raw.githubusercontent.com/hi8735/ai-automation-kit/main/install/install.ps1 | iex

    [1/5] 부터 [5/5] 까지 진행 상황이 나와요. 처음엔 3~5분 걸려요. 창을 닫지 말고 기다려주세요.

  3. 브라우저에서 로그인

    설치가 끝나면 코치가 저절로 켜지고 브라우저가 열려요. Claude 계정으로 로그인 버튼을 누르고, 열린 창에서 로그인하면 자동으로 대화 화면으로 넘어가요.

    i로그인 끝에 브라우저에 코드가 보이면, 복사해서 코치 화면의 "코드 붙여넣기" 칸에 넣어주세요.

  4. 다음부터는 아이콘 더블클릭

    바탕화면의 AI 업무자동화 코치 아이콘을 더블클릭하면 돼요. 검은 창이 하나 같이 뜨는데, 그 창이 코치 엔진이에요. 다 쓰고 닫으면 코치도 꺼져요.

  1. 터미널 열기

    ⌘ Command + Space → 터미널 입력 → Enter.

  2. 아래 한 줄 붙여넣고 Enter

    curl -fsSL https://raw.githubusercontent.com/hi8735/ai-automation-kit/main/install/install.sh | bash

    [1/5] 부터 [5/5] 까지 진행 상황이 나와요. 처음엔 3~5분 걸려요.

  3. 브라우저에서 로그인

    설치가 끝나면 코치가 켜지고 브라우저가 열려요. Claude 계정으로 로그인 → 열린 창에서 로그인 → 자동으로 대화 화면.

  4. 다음부터는 바탕화면 아이콘 더블클릭

    바탕화면의 AI 업무자동화 코치 를 더블클릭하면 터미널 창과 함께 브라우저가 열려요. 터미널 창을 닫으면 코치도 꺼져요.

02

알아두면 좋아요

무엇이 어디에 설치되나요?

Windows 는 내 사용자 폴더 안 AppData\Local\ai-kit, Mac 은 홈 폴더의 ai-kit 한 곳에만 설치돼요. 코치 앱, 전용 파이썬, 키트가 모두 그 안에 있어요. 컴퓨터의 다른 곳은 건드리지 않아요.

내가 넣은 파일과 기록은 어디 있어요?

설치 폴더의 workspace 폴더 안의 inputs(넣은 파일), results(인터뷰 기록), report(리포트), automations(만든 자동화)예요. 코치 화면 왼쪽 "내 파일" 에서도 볼 수 있어요.

새 버전으로 업데이트하려면요?

설치할 때 쓴 한 줄을 다시 붙여넣으면 돼요. 내 기록과 만든 자동화는 그대로 남아요.

설치 중 빨간 글씨가 나왔어요

창 내용을 캡처해서 모임 채팅방에 올려주세요. 회사 PC 는 보안 프로그램이 설치를 막는 경우가 많아요. 그럴 땐 개인 PC 로 해보세요.

브라우저가 안 열려요

브라우저 주소창에 http://127.0.0.1:8790 을 직접 입력하세요. 코치 창(검은 창)이 켜져 있어야 해요.

지우고 싶어요

코치 창을 닫고, ai-kit 폴더와 바탕화면 아이콘을 지우면 끝이에요. 지우기 전에 필요한 기록은 따로 옮겨두세요.

무료 플랜인데 쓸 수 있나요?

아쉽지만 안 돼요. Claude Pro 이상 플랜이 필요해요. 로그인하면 코치가 플랜을 확인해서 알려드려요.
