Claude Code 설치하기

Claude Code 는 내 컴퓨터의 폴더 안에서 파일을 읽고 만들 수 있는 Claude 예요. 키트는 이 위에서 동작해요. 아래 순서대로 하나씩 따라 해 주세요.

데스크톱 앱으로 (추천) 터미널로
설치가 끝나면 이렇게 보여요

claude --version

claude

01

먼저 확인해요

Claude 유료 플랜Pro, Max, Team, Enterprise 중 하나. 무료 플랜에서는 Claude Code 를 쓸 수 없어요. 플랜 확인하기
컴퓨터Windows 10(1809 이후) 또는 11, macOS 13 이상. 인터넷 연결.
i회사 PC 라면 프로그램 설치가 막혀 있을 수 있어요. 막히면 억지로 우회하지 말고, 개인 PC 로 해보시거나 모임 채팅방에 알려주세요.
02

설치 방법 고르기

둘 중 편한 쪽 하나만 하면 돼요. 키트는 둘 다에서 똑같이 동작해요.

명령어가 낯설다면 추천

A. Claude 데스크톱 앱

일반 프로그램처럼 설치하고, 앱 안의 Code 에서 쓰는 방법이에요. 검은 창(터미널)을 쓰지 않아요.

이 방법으로 →
조금 더 가볍게

B. 터미널에 설치

명령어 한 줄을 복사해서 붙여넣는 방법이에요. 이 페이지에서 복사 버튼만 누르면 돼요.

이 방법으로 →
A

데스크톱 앱으로 설치

  1. 앱 내려받기

    claude.com/download 에서 내 컴퓨터(Windows / Mac)용을 받아 설치해요.

  2. 로그인

    앱을 열고 유료 플랜 계정으로 로그인해요.

  3. Code 열기

    앱 화면에서 Code 를 선택하고, 작업 폴더로 키트 폴더(CLAUDE.md 가 보이는 폴더)를 골라요.

  4. 끝! 키트로 돌아가기

    사용설명서의 시작하기로 가서 "신뢰하시겠습니까? → 예", /start 부터 이어가세요.

B

터미널에 설치

터미널은 글자로 컴퓨터에 명령하는 창이에요. 복사해서 붙여넣기만 하면 돼요.

  1. PowerShell 열기

    키보드의 Windows 키를 누르고 PowerShell 이라고 입력 → Windows PowerShell 을 클릭해요. 관리자 권한은 필요 없어요.

    파란(또는 검은) 창 맨 앞에 PS C:\Users\이름> 처럼 PS 가 보이면 맞게 연 거예요.

  2. 설치 명령 붙여넣기

    아래 복사를 누르고, PowerShell 창에서 마우스 오른쪽 클릭(또는 Ctrl+V) 으로 붙여넣은 뒤 Enter.

    irm https://claude.ai/install.ps1 | iex

    설치하는 동안 진행 표시가 안 나올 수 있어요. 다시 PS C:\…> 가 나올 때까지 기다려요.

  3. 새 창에서 확인

    PowerShell 창을 닫고 새로 열어서 아래를 입력해요. 버전 숫자가 나오면 성공이에요.

    claude --version

  4. 처음 실행하고 로그인

    claude

    브라우저가 열리면 유료 플랜 계정으로 로그인하고 허용을 눌러요. 끝나면 사용설명서의 시작하기로 돌아가세요.

i선택 사항: Git for Windows 를 설치해 두면 Claude Code 가 일부 기능을 더 안정적으로 써요. 없어도 키트는 동작해요.

  1. 터미널 열기

    ⌘ Command + Space 를 누르고 터미널 이라고 입력 → Enter.

  2. 설치 명령 붙여넣기

    아래 복사를 누르고 터미널에 ⌘+V 로 붙여넣은 뒤 Enter.

    curl -fsSL https://claude.ai/install.sh | bash

  3. 새 창에서 확인

    터미널을 닫고 새로 열어서 입력해요. 버전 숫자가 나오면 성공이에요.

    claude --version

  4. 처음 실행하고 로그인

    claude

    브라우저가 열리면 유료 플랜 계정으로 로그인해요. 끝나면 사용설명서의 시작하기로 돌아가세요.

?

이런 메시지가 나오면

'claude' 은(는) … 인식되지 않습니다 / command not found
설치 직후 같은 창에서 실행해서 그래요. 창을 닫고 새로 열어 다시 해보세요. 그래도 안 되면 컴퓨터를 한 번 재시작해 보세요.
'irm' is not recognized …
PowerShell 이 아니라 명령 프롬프트(CMD)에서 실행한 거예요. 위 1단계대로 PowerShell 을 열어서 다시 붙여넣으세요.
권한 / 차단 / 정책 관련 오류
회사 PC 보안 정책일 가능성이 커요. 우회하지 말고 개인 PC 를 쓰거나 모임 채팅방에 알려주세요.
로그인했는데 사용할 수 없대요
무료 플랜 계정일 수 있어요. Pro 이상 플랜이 필요해요.
