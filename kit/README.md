# AI 업무자동화 키트 (v1.2)

Claude Code 와 대화하면서 **내 업무 중 무엇을 자동화할 수 있는지** 찾아보고, 가능하면 **첫 자동화까지 직접 만들어보는** 키트입니다.

- 걸리는 시간: 30~60분 (중간에 끊겨도 다시 이어서 할 수 있어요)
- 끝나면 진행자에게 보낼 리포트가 만들어집니다. **회사 정보는 모두 지운 형태**이고, 보내기 전에 직접 확인합니다.
- 미리 리포트를 보내주신 분들 중에서 모임 당일 1:1 로 더 깊게 봐드립니다.

📖 그림과 예시가 있는 사용설명서: https://hi8735.github.io/ai-automation-kit/

---

## 시작하기 전에 필요한 것

- **Claude Code** 가 설치되어 있고 로그인되어 있어야 합니다 (Claude 유료 플랜).
  - 아직 없으면: https://hi8735.github.io/ai-automation-kit/install.html
  - 터미널에서 쓰는 Claude Code, 또는 **Claude 데스크톱 앱의 Code** 둘 다 됩니다.

---

## 1. 압축 풀기

### Windows
1. 받은 zip 파일(`ai-automation-kit.zip`)을 **오른쪽 클릭 → 모두 압축 풀기**.
2. 풀 위치는 찾기 쉬운 곳으로 바꿔주세요. 추천: `C:\ai-work`
   - 바탕화면이나 OneDrive 폴더는 피하는 게 좋아요 (동기화 때문에 문제가 생길 수 있어요).
3. ⚠️ **폴더가 두 겹으로 생길 수 있어요.** `C:\ai-work\ai-automation-kit\ai-automation-kit\` 처럼요.
   → **`CLAUDE.md` 파일과 `inputs` 폴더가 바로 보이는 폴더**가 진짜 폴더입니다. 거기서 실행해야 해요.

### Mac
1. 받은 zip 을 더블클릭하면 풀립니다.
2. 풀린 `ai-automation-kit` 폴더를 찾기 쉬운 곳(예: `문서` 폴더)으로 옮겨주세요.

---

## 2. Claude Code 실행

### 터미널에서 쓰는 경우
- **Windows:** 키트 폴더(`CLAUDE.md` 가 보이는 폴더)를 연 상태에서, 위쪽 주소창에 `cmd` 라고 치고 Enter → 열린 창에 `claude` 입력 후 Enter.
- **Mac:** Finder 에서 키트 폴더를 오른쪽 클릭 → **폴더에서 새로운 터미널 열기** → `claude` 입력 후 Enter.
  - 메뉴가 안 보이면: 터미널을 열고 `cd ` (cd 다음 한 칸 띄우기) 를 친 뒤 키트 폴더를 터미널 창에 끌어다 놓고 Enter → `claude` 입력.

### 데스크톱 앱에서 쓰는 경우
- Claude 데스크톱 앱 → **Code** → 작업 폴더로 키트 폴더(`CLAUDE.md` 가 보이는 폴더)를 선택.

⚠️ 처음 실행하면 **"이 폴더를 신뢰하시겠습니까? (Do you trust the files in this folder?)"** 같은 질문이 나와요 → 꼭 **예(Yes)** 를 선택하세요. 이걸 눌러야 키트가 제대로 동작해요.

진행하다 보면 Claude 가 파일을 만들거나 프로그램을 실행할 때 **허락을 묻는 창**이 뜰 수 있어요. Claude 가 바로 앞에서 무엇을 하려는지 설명하니, 괜찮으면 **예(Yes)** 를 눌러주세요.

## 3. 시작

```
/start
```

를 치고 Enter. (그냥 "안녕하세요" 라고 쳐도 시작돼요.)

그다음부터는 Claude 가 하나씩 물어봅니다. 편하게 대화하듯 답하시면 돼요.

---

## 쓸 수 있는 명령

| 명령 | 하는 일 |
|---|---|
| `/start` | 인터뷰 시작 (또는 이어서 하기) |
| `/build` | 고른 업무로 자동화 만들기 (보통 인터뷰 끝에 자연스럽게 이어져요) |
| `/run 이름` | 만든 자동화 다시 실행하기 (예: `/run weekly-report`) |
| `/report` | 진행자에게 보낼 리포트 만들기 |

---

## 폴더 안내

| 폴더 | 용도 |
|---|---|
| `inputs` | 업무 파일 샘플, 화면 캡처를 넣는 곳 |
| `results` | 인터뷰 기록. **실제 업무 내용이 들어가니 보내지 마세요.** 내 PC 에만 둡니다 |
| `report` | 제출용 리포트 (회사 정보 지운 것). **이것만 보내주세요** |
| `automations` | 내가 만든 자동화 (어떻게 처리하는지 적은 문서 + 사용법) |
| `outputs` | 자동화가 만든 결과물 (자동화를 처음 만들 때 생겨요) |

## 업무 파일을 넣을 때

- 넣은 파일은 Claude 로 전송됩니다. **회사 규정을 한번 확인**해 주세요.
- 가능하면 이름·연락처·금액 같은 민감한 부분을 지우거나 가짜 값으로 바꾼 **사본**을 넣어주세요. 그래도 충분히 됩니다.
- **한글(.hwp)·워드 파일**은 PDF 로 저장해서 넣어주세요. **엑셀**은 그대로 넣어도 되고, 안 열린다고 하면 Claude 가 방법을 알려드려요.
- 화면 캡처는 **.png / .jpg** 로 저장해 주세요 (아이폰 사진 .heic 는 안 읽혀요).

## 막혔을 때

- **중간에 멈췄거나 창을 닫았어요** → 같은 폴더에서 Claude Code 를 다시 열고 `/start`. 하던 데서 이어집니다.
- **"사용량 한도" 같은 메시지가 나와요** → 잠시 후 다시 열고 `/start` 하면 이어집니다.
- **키트 새 버전을 받았어요** → 새 zip 을 **원래 키트 폴더와 같은 위치에 풀고**, "파일을 바꾸시겠습니까?" 가 나오면 **예**. 내 인터뷰 기록(`results`)과 만든 자동화는 그대로 남아요.
- **`/start` 가 안 먹혀요** → `CLAUDE.md` 가 보이는 폴더에서 실행했는지 확인해 주세요 (위 "폴더가 두 겹" 참고).
- **그 밖에** → 어디서 어떻게 막혔는지(화면 캡처면 더 좋아요) 모임 채팅방에 남겨주세요. 키트를 고쳐서 다시 올릴게요.

## 리포트 보내기

`/report` 가 끝나면 안내가 나와요.
- 보내는 곳: **woo.noh@healingpaper.com**
- 메일 제목: `[AI자동화] 당근닉네임 - 직무`
- 첨부: `report` 폴더 안의 `submit-○○.md` 파일
- 진행자는 **당근 모임 닉네임**으로 1:1 연락을 드려요. 리포트에 닉네임이 정확히 적혔는지 확인해 주세요.
- 보내주신 리포트는 1:1 대상을 고르는 데 쓰고, 모임에서 닉네임 없이 묶어서 사례로 소개할 수 있어요.
