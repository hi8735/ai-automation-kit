# 파일 형식별로 읽는 법

사용자가 `inputs/` 에 파일을 넣으면 형식에 따라 아래처럼 처리한다. 못 읽는 형식이면 **사용자를 탓하지 말고** 쉬운 변환 방법을 안내한다.

| 형식 | 바로 읽힘? | 안 될 때 안내 |
|---|---|---|
| `.txt` `.md` `.csv` | 예 | — (CSV 한글이 깨지면 `cp949` 로 다시 읽는다) |
| `.pdf` | 예 | 스캔한 PDF 라 글자가 안 읽히면 화면 캡처(.png)로 |
| `.png` `.jpg` (화면 캡처, 사진) | 예 | — |
| `.heic` (아이폰 사진) | 아니요 | "사진을 캡처 화면처럼 .png/.jpg 로 저장해서 넣어주세요" |
| `.xlsx` `.xls` (엑셀) | Python 있으면 예 | Python 없으면: "엑셀에서 **다른 이름으로 저장 → CSV UTF-8 (쉼표로 분리)** 로 저장한 사본을 넣어주세요." 시트가 여러 개면 필요한 시트마다 따로 저장. (설치는 `/build` 에서 필요할 때 — `guide/python-setup.md`) |
| `.docx` (워드) | Python 있으면 예 (`python-docx`) | "워드에서 **다른 이름으로 저장 → PDF** 로 저장해서 넣어주세요." |
| `.hwp` `.hwpx` (한글) | 아니요 | "한글에서 **다른 이름으로 저장 → PDF** 로 저장하거나, 내용을 복사해서 대화창에 붙여넣어 주세요." |
| `.pptx` (파워포인트) | Python 있으면 예 (`python-pptx`) | "**PDF 로 저장**해서 넣어주세요." |
| 메일 | — | "메일 내용을 복사해서 대화창에 붙여넣거나, 메일을 PDF 로 저장해 넣어주세요." |
| 카카오톡·메신저 대화 | — | "대화 내보내기(텍스트 저장) 한 파일을 넣거나, 필요한 부분만 복사해 붙여넣어 주세요. 다른 사람 이름·번호가 많으면 지워주세요." |

원칙:
- 인터뷰 중에는 **설치 없이 되는 방법**(CSV·PDF 로 저장, 복사·붙여넣기)을 먼저 안내한다.
- 자동화를 매주 쓸 거라면, 사용자가 매번 변환하는 수고가 생기는지 확인한다. 매번 변환해야 하면 `/build` 에서 Python 으로 원본 형식을 바로 읽는 방식을 제안한다.
