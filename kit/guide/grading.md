# 자동화 가능성 판단 기준 (A~D)

등급은 "이 키트 안에서, 이 사람이, 오늘~이번 주 안에 실제로 쓸 수 있게 되는가" 를 기준으로 매긴다. 기술적으로 언젠가 가능한지가 아니다.

## 등급

### A — 지금 이 폴더에서 바로 가능
- 입력이 **파일로 손에 들어온다** (엑셀, CSV, 워드, 한글 문서를 PDF 로 저장한 것, PDF, 텍스트, 메일 내용을 복사한 것, 화면 캡처).
- 처리가 **규칙으로 대부분 설명된다**. 판단이 섞여도 사람이 마지막에 확인하면 된다.
- 결과가 **파일이나 글**이다 (보고서, 표, 정리본, 초안, 답장 문안).
- 예: 여러 엑셀 합쳐 집계, 같은 양식 문서 초안, 회의록 정리, 문의 답장 초안, PDF 내용을 표로, 자료 분류.

### B — 연결 설정이 필요
- 입력이나 결과가 **외부 서비스 안에** 있다 (Gmail·아웃룩 메일함, 구글 드라이브·시트, 노션, 슬랙, 캘린더).
- Claude Code 에 해당 서비스 연결(커넥터)을 설정하면 가능하지만, 계정 연결·권한·회사 정책 확인이 필요하다.
- 오늘은: **수동으로 파일을 내려받아 넣는 방식으로 A 등급으로 낮춰서** 먼저 해볼 수 있는지 본다. (예: 메일을 복사해 붙여넣기, 시트를 엑셀로 내려받기)

### C — 웹 화면 자동조작이 필요
- 사내 시스템·웹사이트에 **로그인해서 클릭·입력**해야 하고, 파일로 내려받는 기능이 없다.
- 브라우저 자동조작으로 가능은 하지만 **화면이 조금만 바뀌어도 깨지고**, 회사 보안 정책에 걸릴 수 있다.
- 오늘은: 그 시스템에서 **엑셀/CSV 내보내기 기능**이 있는지 먼저 묻는다. 있으면 그 뒤 단계는 A 등급이다.

### 업종 주의 — 공공기관·금융·의료
- 이런 곳은 외부 AI(클라우드) 사용 자체를 지침으로 제한하는 경우가 많다. 업무 데이터를 넣는 자동화를 권하기 전에 "회사(기관)에 AI 사용 지침이 있는지 먼저 확인해 보세요" 라고 한 번 말한다. 가짜 값 샘플로 방법을 익히는 것은 괜찮다.

### D — 맞지 않음
- 핵심이 **사람의 판단·관계·책임**이다 (협상, 평가, 최종 승인, 민감한 상담).
- 데이터가 **반출 금지**이거나 개인정보가 핵심이다.
- 빈도가 너무 낮아 만드는 수고가 더 크다 (1년에 한두 번).
- 이 경우에도 **일부분**은 도울 수 있는지 본다 — 준비 자료 정리, 초안, 체크리스트.

## 효과 가늠

- 월 소요시간 = 빈도 × 1회 시간.
- 자동화 후 시간은 **사람이 확인하는 시간**을 반드시 포함한다. 보통 A 등급은 원래 시간의 20~40% 정도 남는다고 보고, 근거와 함께 말한다. 과장하지 않는다.

## "오늘 바로 성공할 일" 고르는 기준

1. A 등급
2. 샘플 파일을 지금 구할 수 있다
3. 범위가 작다 (전체 업무 중 한 덩어리만 떼어내도 된다)
4. 결과가 맞았는지 사용자가 바로 판단할 수 있다
