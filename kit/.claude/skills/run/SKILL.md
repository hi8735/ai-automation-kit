# /run — 만든 자동화 실행

사용자가 `/build` 로 만든 자동화는 `automations/<이름>/AUTOMATION.md` 에 있다. 이 스킬은 그 문서를 읽고 **문서에 적힌 그대로** 실행한다.

## 절차

1. **어떤 자동화인지 정하기.**
   - 사용자가 이름을 말했으면 (`/run weekly-report`) 그 폴더를 찾는다.
   - 이름 없이 `/run` 만 쳤으면 `automations/` 안의 폴더 목록을 번호로 보여주고 고르게 한다. 하나뿐이면 "○○ 를 실행할까요?" 라고 확인만 한다.
   - `automations/` 가 비어 있으면: "아직 만든 자동화가 없어요. `/start` 로 인터뷰부터 해볼까요?"
2. **`AUTOMATION.md` 를 읽고 그대로 따른다.** 입력 확인 → 처리 단계 → 규칙 → 결과 저장. 문서에 없는 방식으로 임의로 바꾸지 않는다.
   - **먼저 `inputs/` 를 살펴본다.** 붙여넣기를 요청하기 전에, `inputs/` 에 있는 파일 중 이번에 쓸 만한 것(최근에 넣은 것, 문서에 적힌 형식과 맞는 것)을 보여주고 "이 파일로 할까요?" 라고 묻는다.
   - 쓸 파일이 없거나 형식이 다르면 무엇이 필요한지 알려주고 멈춘다.
   - 프로그램(script.py 등) 실행이 필요하면 실행 직전에 한 문장으로 알리고, 확인 창이 뜨면 '예' 를 눌러달라고 안내한다.
3. **결과 보고.** 결과 파일 위치와, "확인 필요" 로 표시된 항목을 짧게 알려준다.
4. **고칠 점이 생기면.** 사용자가 "이번엔 이렇게 해줘" 처럼 규칙을 바꾸고 싶어 하면, 이번만 바꿀지 앞으로도 바꿀지 묻고, 앞으로도면 `AUTOMATION.md` 를 고친다 (고치기 전에 무엇을 바꾸는지 보여준다).
