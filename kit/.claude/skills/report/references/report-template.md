# 리포트 형식

맨 위 YAML 블록은 진행자가 여러 리포트를 한꺼번에 비교하는 데 쓴다. 항목 이름을 바꾸지 않는다. 값은 정보 제거 규칙을 적용한 뒤의 값이다.

```markdown
---
kit_version: v1.5
daangn_nickname: 하늘바다          # 당근 모임 닉네임 (본인 확인 받은 그대로)
job: 구매 담당
industry: 중견 제조업
track: 2                       # 1 = 하고 싶은 일이 분명했음, 2 = 탐색
top_task: 협력사별 발주 현황 주간 집계
top_task_grade: A              # A | B | C | D
monthly_hours_now: 12          # 선택한 업무의 현재 월 소요시간 (대략)
monthly_hours_after: 2         # 자동화 후 예상
biggest_task: 월말 정산 대사    # 효과가 가장 큰 일 (선택한 일과 같으면 같은 값)
biggest_task_grade: B
build_result: 성공             # 성공 | 일부 | 시도 안 함
has_samples: 예                # 샘플 파일을 실제로 넣어봤는지
python: 있음                   # 있음 | 없음 | 설치 실패 | 확인 못 함
os: windows
wants_from_1on1: 월말 정산도 자동화할 수 있는지, 사내 ERP 에서 자료 뽑는 부분
---
```

작성 요령:
- "한눈에 보기" 는 5줄을 넘기지 않는다.
- 해당 없는 섹션은 "해당 없음" 한 줄로 둔다. 지우지 않는다 (형식 통일).
- 인터뷰를 중간까지만 했으면 `build_result: 시도 안 함` 으로 두고, 비어 있는 YAML 값은 `미정` 으로 쓴다.
- **단, `daangn_nickname` 은 `미정` 으로 둘 수 없다.** 비어 있으면 리포트를 저장하기 전에 당근 닉네임을 물어보고, 받기 전에는 저장하지 않는다.
