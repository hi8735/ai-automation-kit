# 정보 제거 규칙

목표: 이 리포트가 **회사 밖 누구에게 가더라도 어느 회사, 누구의 일인지 알 수 없게** 한다. 그러면서도 "어떤 직무의 어떤 업무가 어떻게 자동화될 수 있는가" 는 충분히 전달돼야 한다.

## 지우거나 바꾸는 것

| 원래 내용 | 처리 | 예시 |
|---|---|---|
| 회사명, 브랜드명, 계열사명 | 삭제 → 업종·규모로 일반화 | "○○전자" → "중견 제조업" |
| 학교·학원·병원·의원·약국·공공기관·가게 상호 | 삭제 → 종류로 | "○○고" → "고등학교", "○○의원" → "동네 의원", "○○베이커리" → "동네 빵집" |
| 부서명 중 회사 고유한 것 | 일반 부서명으로 | "글로벌SCM2팀" → "구매팀" |
| 사람 이름, 직함+성 | 삭제 → 역할로 | "김 팀장님" → "팀장" |
| 고객사·거래처·협력사 이름 | 삭제 → 관계로 | "△△마트" → "주요 거래처" |
| 제품명, 프로젝트명, 서비스명 | 삭제 → 종류로 | "Project Aurora" → "신규 프로젝트" |
| 사내 시스템·내부 도구 이름 | 일반명으로 | 회사가 자체로 만든 시스템·내부 별칭은 "사내 시스템", "사내 CRM" 처럼. 특정 업계 전용·소수만 쓰는 도구도 종류로 |
| **널리 쓰이는 공개 서비스** | **그대로 둔다** | 엑셀, 구글 시트, 지메일, 아웃룩, 슬랙, 카카오톡, 노션, 메타 광고, 네이버 검색광고, 배민, 네이버 플레이스, 더존, SAP 등 — 회사를 특정하지 못하고, 진행자가 자동화 방법을 고르는 데 꼭 필요한 정보다 |
| 금액, 매출, 단가, 수량 등 구체 수치 | 범위나 규모로 | "월 3,420만원" → "월 수천만원 규모" |
| 업무 시간·빈도 수치 | **유지** (회사 정보가 아님, 선정에 필요) | "주 3회, 1회 40분" 그대로 |
| 이메일, 전화번호, 주소, 계좌, 사번 | 삭제 | — |
| 지역·지점명 | 지점명은 지우고, 지역은 시·도까지만 (작은 가게는 지역도 지운다) | "강남점" → "지점", "망원동" → "서울" |
| 업무 파일·메일·화면의 실제 내용 | **인용하지 않는다** | "어떤 항목이 있는 엑셀" 정도로만 서술 |
| 스크린샷, 첨부 이미지 | **포함하지 않는다** | — |
| 파일명 | 회사·사람·제품명이 들어 있으면 일반화 | "2026_○○전자_발주.xlsx" → "발주 엑셀" |

## 그대로 두는 것

- 업종(일반화), 직무, 연차 정도 (본인이 말했을 때)
- 업무의 종류와 흐름, 빈도, 소요 시간
- 쓰는 프로그램의 **종류** (엑셀, 메일, 메신저, 그룹웨어, ERP 등)
- 자동화 진단, 만든 자동화의 방식, 막힌 점

## 사용자 말 인용

- 따옴표로 인용한 사용자 말은 **글자를 바꾸지 않는다.** 그 안에 지워야 할 정보가 있으면 따옴표를 빼고 풀어서 쓴다.

## 애매하면

- 지운다. 리포트에 필요한 건 "어떤 종류의 일인가" 이지 "어디의 무슨 일인가" 가 아니다.
- 본인이 회사를 공개해도 된다고 명시적으로 말해도, 리포트에는 업종 수준까지만 쓴다.

## 자가 점검 목록 (초안 저장 전 하나씩 확인)

1. `results/interview.md` 에 나온 고유명사(회사·사람·고객·제품·프로젝트·사내 시스템 이름)를 목록으로 뽑고, 하나씩 초안에 남아 있는지 찾아본다.
2. 초안에 `@`, `http`, `www`, 전화번호 형태(숫자-숫자-숫자), 주민번호·사번·계좌 형태가 있는지 본다.
3. 원·만원·억·달러·% 가 붙은 숫자가 있는지 본다 → 시간·빈도가 아니면 범위로 바꾼다.
4. 업무 파일 내용을 문장째 옮긴 부분이 없는지 본다.
5. 이미지나 `inputs/` 파일 경로를 넣지 않았는지 본다.
6. 마지막으로, "이 리포트만 보고 회사를 맞힐 수 있을까?" 를 생각해 본다. 맞힐 수 있을 것 같으면 더 일반화한다.
