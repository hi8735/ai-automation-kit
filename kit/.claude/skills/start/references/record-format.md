# 기록 형식 — `results/interview.md`

한 단계가 끝날 때마다 이 파일을 갱신한다. 이 파일은 **본인 PC 에만 남는 작업 기록**이다. 회사·사람·거래처 이름, 금액을 **지우지 말고 들은 그대로** 적는다 — `/report` 가 이 기록과 대조해서 무엇을 지울지 판단한다. 정보 제거는 `/report` 에서만 한다.

후보 표의 번호는 나온 순서대로 매기고 바꾸지 않는다. 등급 칸은 대략이라도 채운다.

형식을 바꾸지 않는다 — 키트 새 버전에서도 이 기록을 읽고 이어가야 한다.

```markdown
---
kit_version: v1.2
daangn_nickname: (당근 모임 닉네임 — 리포트·메일 제목에 쓴다)
call_name: (대화에서 부를 호칭, 따로 없으면 당근 닉네임)
os: windows | mac
python: 있음 (버전) | 없음 | 확인 못 함
track: 1 | 2
stage: welcome | track | deep-dive | diagnosis | build | done
report_submitted: no | yes
next: (다음에 이어서 할 일 한 줄 — 매 단계 덮어쓴다. 예: "후보 3번(블로그) 빈도 묻기부터")
updated: YYYY-MM-DD HH:MM   # 날짜와 시각 둘 다
---
```
